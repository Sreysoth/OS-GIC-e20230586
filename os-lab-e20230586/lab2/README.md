# OS Lab 2 — Linux Navigation & File Management

## Overview
This lab demonstrates directory navigation, relative and absolute path resolution, and file manipulation across organizational department hierarchies in Linux.

## Completed Tasks
- **Core 1:** Built the departmental directory structure (`Finance`, `Marketing`, `Support`) under `TechCorp/`.
- **Core 2:** Managed reports by executing relative moves to `reports/`, absolute path relocations, and duplication to department storage and archives (`first-original.txt`).
- **Core 3:** Verified byte-for-byte data integrity with `cmp`, analyzed directory-dependent path traversal errors, and resolved relative paths using `..`.
- **Plus & Challenge:** Resolved multi-level relative path copies across dynamic subfolders and evaluated shell globbing behavior with wildcard expansions.
